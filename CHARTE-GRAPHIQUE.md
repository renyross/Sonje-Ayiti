# Charte graphique — Sonje Ayiti

Palette adaptée visuellement du logo fourni. Ces couleurs sont des approximations, à confirmer avec le fichier source du logo.

| Couleur | Valeur | Usage |
| --- | --- | --- |
| Vert du logo | `#00A651` | Signes graphiques, filets, repères |
| Vert lisible | `#08763F` | Titres, navigation, liens sur fond clair |
| Vert profond | `#123F2C` | Sections sombres, pied de page |
| Orange | `#EE941B` | Don, parrainage, appels à l’action avec texte sombre |
| Orange foncé | `#AE5D08` | Texte orange sur fond clair |
| Lavande | `#A7A1CB` | Décoration, repères du programme santé |
| Lavande foncé | `#615D91` | Texte secondaire violet |
| Blanc | `#FFFFFF` | Surfaces principales |
| Vert très clair | `#EFF7EF` | Éducation, approche communautaire |
| Crème | `#FFF6E8` | Parrainage |
| Lavande clair | `#F0EEF8` | Impact, santé |
| Texte | `#233C30` | Texte sombre et texte sur boutons orange |

Manrope pour les titres, DM Sans pour le corps. Titres affirmés, grands visuels, boutons géométriques et alternance de sections claires et sombres.

Les trois piliers sont identifiés par le vert (éducation), l’orange (économie) et le lavande (santé), toujours accompagnés de leur intitulé.

Le logo de l’en-tête et du pied de page est conservé localement dans `assets/sonje-ayiti-logo.jpg`, récupéré sur https://sonje-ayiti.org/wp-content/uploads/2022/05/SAO_plant-logo.jpg. Son dessin correspond à la référence fournie, avec des couleurs plus vives. Le fichier est affiché sans filtre ni recadrage.


## Harmonisation des sections
Trois couleurs directrices : vert `#08763F`, orange `#EE941B`, lavande `#A7A1CB`. Fonds clairs : vert `#EFF6F0`, crème orangé `#FFF6E8`, lavande `#F3F0F8`. Le vert profond `#123F2C` structure les territoires, la newsletter et le pied de page. L’orange est réservé aux accents et appels au soutien ; le lavande accompagne les programmes et la mesure d’impact.


## Fonds de sections — règle finale
Limiter les arrière-plans des sections de l’accueil à trois teintes : blanc `#FFFFFF`, lavande très clair `#F3F0F8`, vert profond `#123F2C`. Le hero conserve sa photographie. L’orange reste un accent de bouton ou de décoration, jamais un fond de section.
